# 窥见你的百态 · 收藏每个朝夕

一个文艺风格的**照片墙** HTML 单页应用，采用 Swiper 全屏垂直滑动，每页以自适应网格展示全部照片，中央文案覆盖层统合页面。

## 项目结构

```
love-gallery/
├── index.html           # 单页应用（所有页面）
├── README.md            # 本文件
├── .nojekyll            # 禁用 GitHub Pages Jekyll 处理
├── _copy.json           # 文案配置
├── _scan.txt            # 素材扫描报告
└── assets/
    └── photos/
        ├── 他人拍卓/          (10张)
        ├── 卓双手对镜拍/      (23张)
        ├── 对镜拍+祖传剪刀手/ (9张)
        ├── 卖萌卓/            (15张)
        ├── 委屈卓/            (4张)
        ├── 小困卓/            (9张)
        ├── 认真生活的卓/      (19张)
        ├── 卓和同学/          (5张)
        ├── 卓和家人/          (21张)
        ├── 两人为数不多的合影/ (5张)
        ├── 就是很美的卓/      (16张)
        └── 感觉有艺术感_很喜欢的几张/ (3张)
```

## 技术栈

- **Swiper 11** - 触摸滑动翻页（CDN）
- **Ma Shan Zheng 字体** - Google Fonts 书法体（CDN）
- **CSS Grid** - 自适应照片网格排版
- **JS 实时计时器** - 首页正计时

## GitHub Pages 部署步骤

1. **创建 GitHub 仓库**（Public）
2. **上传所有项目文件**（可用 GitHub 网页直接上传，或 git 命令行）
3. **启用 Pages**：仓库 Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main`，目录选 `/ (root)` → Save
4. 等待约 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/`

## 自定义

- 修改 `_copy.json` 中的文案后重新运行 `build_gallery.py`
- 在 `assets/photos/` 下添加新分类文件夹并更新 `_copy.json` 后重新构建
